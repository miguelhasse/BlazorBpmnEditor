XML conventions: moddle-xml uses the type name for complex child tags, applying
xml.tagAlias="lowerCase" only when the package requests it (first character only).
Without that hint, case is retained. xml.serialize="property" and "xsi:type"
use the property's name as the tag; xsi:type additionally carries the actual type.
Primitive values and references also use property names; isBody uses text content.
See https://github.com/bpmn-io/moddle-xml/blob/main/lib/write.js (nameToAlias,
collectContainments). The registry retains serialization hints and maps declared
child order accordingly; parentless element lookup cannot disambiguate xsi:type
polymorphism. Unknown XML remains opaque rather than guessing a derived type.
